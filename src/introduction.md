# Welcome

Welcome to **LLMs from Scratch to AI Agents**.

This textbook is a long-term learning project designed to help software engineers understand modern Artificial Intelligence from first principles.

The objective is not merely to learn how to use AI tools, but to understand:

* Why they exist
* How they work internally
* The mathematics behind them
* Their implementation details
* Their enterprise applications

This textbook is written primarily for Java developers transitioning into AI.

No prior Machine Learning or AI experience is required.

## What You Will Learn

By the end of this book, you should be able to:

* Understand Machine Learning fundamentals
* Explain Neural Networks
* Understand Tokenization and Embeddings
* Explain Attention Mechanisms
* Understand Transformer Architecture
* Explain GPT models
* Understand LLM training pipelines
* Build Retrieval-Augmented Generation systems
* Build AI Agents
* Use Spring AI and LangChain4j
* Design enterprise-grade AI solutions

## Learning Philosophy

Throughout this book we follow one simple principle:

> Understand the Why before the How.

Every chapter starts with motivation and intuition before moving into mathematics and implementation.

## Who This Book Is For

This book is ideal for:

* Java Developers
* Spring Boot Developers
* Full Stack Developers
* Technical Leads
* Architects
* Engineers interested in AI

## Living Textbook

This is a living textbook.

As AI evolves, new editions and updates will be added while preserving the historical context and foundational concepts.
