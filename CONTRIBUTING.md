# Contributing

Thank you for your interest in contributing.

## Before Contributing

Please:

* Read the README
* Review the ROADMAP
* Search existing issues
* Discuss major changes before implementation

## Contribution Types

Contributions may include:

* Typo corrections
* Grammar improvements
* Technical corrections
* Additional examples
* Improved diagrams
* Updated references
* Additional exercises

## Pull Request Guidelines

1. Create a feature branch.
2. Make focused changes.
3. Keep commits descriptive.
4. Ensure mdBook builds successfully.
5. Submit a pull request.

## Chapter Quality Standards

Each chapter should:

* Explain motivation
* Provide intuition
* Include technical explanations
* Include practical examples
* Remain beginner friendly
* Maintain consistency with existing chapters

## Code Examples

Code examples should:

* Be minimal
* Be educational
* Be easy to understand
* Include comments where helpful

## Respect the Vision

The goal of this project is to teach AI from first principles rather than treating AI as a black box.
