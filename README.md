# LLMs from Scratch to AI Agents

> A complete AI textbook for Java developers, built chapter-by-chapter in public.

## Vision

This repository contains a living textbook that teaches Artificial Intelligence from first principles all the way to building enterprise-grade AI agents.

The goal is not simply to learn how to call an LLM API. Instead, this project focuses on understanding the internal workings of modern AI systems, including:

* Machine Learning
* Deep Learning
* Neural Networks
* Natural Language Processing
* Embeddings
* Attention Mechanisms
* Transformers
* GPT Models
* Training and Fine-Tuning
* Retrieval-Augmented Generation (RAG)
* AI Agents
* Model Context Protocol (MCP)
* Spring AI
* LangChain4j
* Enterprise AI Architecture

The textbook is written from the perspective of an experienced Java developer transitioning into AI.

---

## Target Audience

This textbook is designed for:

* Java Developers
* Spring Boot Developers
* Full Stack Developers
* Software Engineers
* Solution Architects
* Technical Leads
* Engineers interested in AI and LLMs

No prior AI or Machine Learning experience is required.

## Learning Philosophy

This project follows a simple principle:

> Understand the "Why" before the "How".

Every chapter is structured to answer:

* Why was this concept invented?
* What problem does it solve?
* How does it work internally?
* What mathematics support it?
* How would I implement it?
* How is it used in enterprise systems?

The objective is to eliminate "black box" learning.
